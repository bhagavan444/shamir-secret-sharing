# 📖 Overview

This project implements **Shamir's Secret Sharing** using **Lagrange Interpolation** to reconstruct the **secret (constant term)** of a polynomial from encoded shares.

It demonstrates cryptographic concepts, polynomial interpolation, arbitrary-precision arithmetic using **BigInt**, and multi-base number conversion in **Node.js**.

---

# ✨ Features

- 🔐 Shamir's Secret Sharing
- 📈 Lagrange Interpolation
- 🔢 Multi-base Number Conversion (2–16)
- ♾️ BigInt Arithmetic
- 📂 JSON Input
- 💾 JSON Output
- 🖥 Interactive CLI
- ⚡ Zero External Dependencies

---

# 🏗 Algorithm Workflow

```text
JSON Input
     │
Decode Base Values
     │
Generate (x,y) Points
     │
Lagrange Interpolation
     │
Evaluate f(0)
     │
Recover Secret
```
